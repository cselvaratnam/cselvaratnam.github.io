{% comment %} Structured data — a machine-readable statement of who Christian is. This file OVERRIDES the theme's own `_includes/schema.html`, which emits a bare Person with nothing but a name. Overriding rather than adding is deliberate: two Person blocks describing the same man is worse than one, and leaves search engines to guess which is authoritative. Keep it as one block. What it buys: search engines can tie this site to the same person behind the social accounts listed in `sameAs`, rather than treating each as a stranger. That is what makes a name search resolve to one person instead of several. `sameAs` is a claim of identity, so only put a profile here if you are certain it is his. A wrong URL associates him with someone else. {% endcomment %}
