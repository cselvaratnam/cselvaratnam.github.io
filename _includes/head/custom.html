{% comment %} Structured data — a machine-readable statement of who Christian is. Minimal Mistakes emits no schema.org markup of its own. This file overrides the theme's empty `head/custom.html`, which exists precisely so a site can add its own tags to without copying the whole theme include. What it buys: search engines can tie this site to the same person behind the social accounts listed in `sameAs`, rather than treating each as a stranger. That is what makes a name search resolve to one person instead of several. `sameAs` is a claim of identity, so only put a profile here if you are certain it is his. A wrong URL associates him with someone else. {% endcomment %}
